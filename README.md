# ドライブ荷重マッピング

iPhone の GPS と加速度センサーで走行を記録し、荷重（加速度の逆向き）の移り変わりを G-G ダイアグラムで振り返るアプリ。

## 使う前に

iPhone は車載ホルダーに固定する。走行中に端末が動くと、記録した荷重の向きが狂う。

キャリブレーションは走行ごとに行う。取り付け角度は毎回わずかにずれるため、前回の結果は使い回さない。

## Expo Go での起動手順

1. 依存パッケージをインストールする

   ```bash
   npm install
   ```

2. 開発サーバーを起動する

   ```bash
   npx expo start
   ```

3. iPhone に Expo Go アプリを入れ、最新の状態にしておく
4. iPhone と PC を同じ Wi-Fi に接続する
5. Expo Go アプリでターミナルに表示された QR コードをスキャンする

## 初回走行での確認手順

安全な場所（交通量の少ない直線道路や広い駐車場など）で、キャリブレーションの確認段階（荷重の向きを矢印で表示する画面）で次を確かめる。

- ブレーキを踏む → 矢印が**前**を向く
- 加速する → 矢印が**後ろ**を向く
- 右コーナーを曲がる → 矢印が**左**を向く

すべて体感と一致したら「記録を開始」を押す。一致しない場合は「やり直す」を押してキャリブレーションをやり直す。

## 既知の制約

- 記録はアプリを前面に置いている間だけ動作する
- 坂道の傾きは iOS の重力除去に任せており、車体の傾き分の補正は行わない
