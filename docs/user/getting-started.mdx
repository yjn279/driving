## 用意するもの

- iPhone
- 車を運転する間、iPhone を固定しておける車載ホルダー
- Expo Go（iPhone にインストールしておくアプリ）

キャリブレーション（後述）は、iPhone を車載ホルダーに取り付けた向きを求めるものです。走行のたびに
自動で行われます。

## 起動する

開発機（このアプリのソースコードがあるパソコン）で、次の 2 つを順に実行します。

```bash
npm install
npx expo start
```

表示された QR コードを、iPhone と同じ Wi-Fi につないだ状態で Expo Go から読み取ると、アプリが起動します。

## 最初に確認される権限

一覧画面で「記録を始める」を押して記録の画面に入ると、次の 2 つの権限を確認するダイアログが
表示されます。

- 位置情報の利用
- モーションセンサー（モーションとフィットネス）の利用

どちらも記録に使うため、許可しないと記録を始められません。許可しなかった場合、それぞれ次の案内が
表示されます。

- 「位置情報の利用が許可されていないため、記録を始められません。設定アプリで位置情報の利用を許可してください。」
- 「モーションセンサーの利用が許可されていないため、記録を始められません。設定アプリでモーションとフィットネスの利用を許可してください。」

権限を許可すると、キャリブレーションへ進みます。手順は「走行を記録する」で説明します。
