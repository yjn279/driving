## この文書の構成

`npm test` で 3 ファイル・28 件が動きます。対象は `src/core/` の純粋な関数です。

テストは[仕様](/developer/specification)の段階に沿って並べています。仕様の並びと同じ順に読めます。

| 節 | 仕様の段階 | 件数 | 対象ファイル |
| :-- | :-- | --: | :-- |
| 1 | 較正（`CAL`） | 15 | `src/core/calibration.test.ts` |
| 2 | 変換（`CRD`） | 10 | `src/core/vehicle-frame.test.ts` |
| 3 | 記録（`REC`） | 3 | `src/core/distance.test.ts` |

「対応仕様」の列に、そのテストが守っている仕様の識別番号を示します。
テストを持たない仕様は「4. テストで固定していない仕様」にまとめています。

## 1. 較正（TST-01〜15）

`src/core/calibration.ts` の判定ロジックを検証します。

| ID | テスト | 何を守るか | 対応仕様 |
| :-- | :-- | :-- | :-- |
| `TST-01` | ばらつきが閾値以下のサンプルが 2 秒分揃うと静止が成立する | 静止判定が正しく成立する条件 | `CAL-02` |
| `TST-02` | 2 秒に満たない時点では静止が成立しない | 判定窓を満たさないうちに先へ進まないこと | `CAL-02` |
| `TST-03` | 途中に大きく外れたサンプルが 1 つ入ると経過がリセットされ、そこから 2 秒分揃うまで成立しない | 停車中でも荷物の積み下ろしなどでセンサーは一瞬乱れる。その直後を「静止」と誤判定しないこと | `CAL-02` |
| `TST-04` | 平均のノルムが 9.81 ± 0.5 m/s² の範囲を外れると静止が成立しない | 重力以外の力が働いている状態を弾くこと | `CAL-03` |
| `TST-05` | 重力ベクトルの平均と逆向きの単位ベクトルを返す | `up` の求め方。座標系の起点そのもので、ここが崩れると以降のすべてが意味を失う | `CAL-04` |
| `TST-06` | 水平成分の平均が閾値以上で向きが安定した状態が判定窓ぶん続くと加速が成立する | 加速判定が正しく成立する条件 | `CAL-05` `CAL-06` |
| `TST-07` | 時速 10 km まで 10 m ほど走る緩やかな発進でも成立する | 判定窓 1 秒・閾値 0.5 m/s² が、急発進を求めず穏やかな発進で満たせる大きさであること | `CAL-05` |
| `TST-08` | 水平成分の平均が閾値に届かない場合は加速が成立しない | 停車中のノイズを「加速」と誤認しないこと | `CAL-05` |
| `TST-09` | 判定窓に満たない時点では加速が成立しない | 判定窓を満たさないうちに `forward` を確定しないこと | `CAL-05` |
| `TST-10` | 個々のサンプルが閾値を割っても、ならした値がまっすぐな加速なら成立する | サンプル 1 つずつに閾値を課す実装にすると、まっすぐ加速していても外れ値 1 つで不成立になる。この回帰を防ぐ | `CAL-07` |
| `TST-11` | ノイズで向きが 1 サンプルごとに振れても、平均の向きが動かなければ成立する | 向きの判定がサンプル単位のノイズに影響されないこと | `CAL-07` |
| `TST-12` | 曲がりながらの加速のように向きが一方向へ動いていく場合は成立しない | 曲がりながらの発進を「まっすぐ」と誤って確定させないこと | `CAL-06` |
| `TST-13` | 向きのずれが許容範囲に収まるなら成立する | ずれ 30 度という境界を、`TST-12` と両側から挟んで固定する | `CAL-06` |
| `TST-14` | 直近の判定窓の水平成分の平均の大きさを返す | 画面に出す数値が、判定に使うのと同じならした値であること。表示と判定がずれると、数値を見て加速しているつもりでも進まない | `CAL-11` |
| `TST-15` | 判定窓に満たない時点では値を返さない | 根拠のない数値を表示しないこと | `CAL-11` |

## 2. 変換（TST-16〜25）

`src/core/vehicle-frame.ts` の座標変換と荷重の符号を検証します。
符号を 1 つ取り違えると記録されるデータ全体が意味を失うため、このファイルがもっとも重い位置にあります。

| ID | テスト | 何を守るか | 対応仕様 |
| :-- | :-- | :-- | :-- |
| `TST-16` | 静止時の重力の平均から `up` を求める | 重力の符号の解釈。iOS では画面を上にして水平に置くと z ≈ -9.81 m/s² になる | `CAL-04` |
| `TST-17` | 加速時のユーザー加速度の平均から `forward` を求める | 水平成分の取り出しと `forward` の向き | `CRD-01` |
| `TST-18` | `right` は `forward × up` になる | 右手系の向き。ここを取り違えると左右が入れ替わる | `CRD-01` |
| `TST-19` | 加速の平均が `up` とほぼ平行で水平成分が取れないときは失敗する | 水平成分が取れない状態で `forward` を確定させないこと。確定させると以降の前後左右の区別ができない | `CAL-08` |
| `TST-20` | ブレーキ（後方加速度）で荷重は前を向く | 荷重 = 加速度の逆向き | `CRD-03` |
| `TST-21` | 加速（前方加速度）で荷重は後ろを向く | 荷重 = 加速度の逆向き | `CRD-04` |
| `TST-22` | 右コーナー（右方加速度）で荷重は左を向く | 荷重 = 加速度の逆向き。左右の入れ替わりを検出できる唯一のテスト | `CRD-05` |
| `TST-23` | 端末を傾けて取り付けても、ブレーキで荷重は前を向く | 傾いた取り付けでも符号が保たれること | `CRD-03` `CRD-07` |
| `TST-24` | 端末を傾けて取り付けても、加速で荷重は後ろを向く | 同上 | `CRD-04` `CRD-07` |
| `TST-25` | 端末を傾けて取り付けても、右コーナーで荷重は左を向く | 同上 | `CRD-05` `CRD-07` |

`TST-23`〜`TST-25` は Y 軸 20 度・X 軸 35 度傾けた端末で同じ 3 つを再現しています。
車載ホルダーで端末が水平に固定されることはまれで、傾いた状態でも符号が保たれることこそが本番の条件です。

## 3. 記録（TST-26〜28）

`src/core/distance.ts` の `haversineDistance`（2 地点間の距離）を検証します。

| ID | テスト | 何を守るか | 対応仕様 |
| :-- | :-- | :-- | :-- |
| `TST-26` | 同一地点の距離は 0 になる | 停車中に距離が積み上がらないこと | `REC-09` |
| `TST-27` | 経度が同じ（南北方向）2 地点の距離が、球面上の弧の長さ（半径 × 緯度差ラジアン）と 1 m 以内で一致する | 緯度方向の計算が球面の幾何と合うこと | `REC-09` |
| `TST-28` | 緯度が同じ（東西方向）2 地点の距離が、緯線に沿った弧の長さ（半径 × cos(緯度) × 経度差ラジアン）と 1 m 以内で一致する | 緯度 60 度を選んでいる。`cos(60°) = 0.5` なので `cos(緯度)` の項が抜けると結果がちょうど 2 倍にずれ、誤差の範囲でごまかせない | `REC-09` |

## 4. テストで固定していない仕様

vitest の対象は `src/core/` の純粋な関数だけです。残る仕様は次の手段で確かめます。

| 仕様 | 確かめる手段 |
| :-- | :-- |
| `PHI-01`〜`PHI-03`（方針） | 何を作るかを決める指針であり、コードの一点に対応しない |
| `SNS-01`〜`SNS-04`（取得） | 実機での記録。センサーのレートは端末側の都合で前後する |
| `CAL-01` `CAL-09` `CAL-10` `CAL-11` の画面の挙動 | 実走行の確認 |
| `CRD-02`（荷重 = 加速度の逆向き） | `TST-20`〜`TST-25` が `CRD-03`〜`CRD-05` を通して間接的に固定する |
| `CRD-06`（左コーナーで荷重は右） | `CRD-05` の対称。実走行の確認で見る |
| `CRD-08`（坂道） | 補正しないという判断であり、コード上の分岐を持たない |
| `REC-01`〜`REC-08`（永続化） | `npx tsc --noEmit` と実機での記録 |
| `VIS-01`〜`VIS-06`（可視化） | `npx tsc --noEmit` ・ `npx expo export --platform ios` と実機での表示 |
| `SCP-01`〜`SCP-06`（対象外） | 実装しないという取り決めであり、対応するコードを持たない |
| `ACP-01`〜`ACP-05`（受け入れ基準） | 実走行の確認 |

実走行での確認手順は[キャリブレーションと記録](/user/driving)にあります。
